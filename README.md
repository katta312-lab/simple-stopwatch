# ストップウォッチ

開始・停止・再開・リセットに対応したシンプルなストップウォッチです。日本語表示、スマートフォン対応、外部ライブラリ不要。

## 使い方

- 「開始」で計測、「停止」で一時停止、「再開」で続きから計測します。
- 停止中に「リセット」でゼロに戻せます。
- キーボードの Space で開始・停止、R でリセットできます。ボタンにフォーカスがある場合の Space は、そのボタンを操作します。
- 時・分・秒・1/100秒を表示します。
- 再読み込み・ページを閉じると計測結果は失われます。
- 非表示タブや端末スリープ中も経過時間を含めます。端末時計を変更すると計測に影響します。

## ローカル表示

`public/index.html` をブラウザーで開くか、以下でローカルサーバーを起動します。

```sh
python3 -m http.server 8787 --directory public
```

## Cloudflare への公開

Cloudflare Workers Static Assets の構成ファイルを同梱しています。

```sh
npx wrangler login
npx wrangler deploy
```

Cloudflare Pages でも `public` ディレクトリを出力先として、ビルドなしで公開できます。
